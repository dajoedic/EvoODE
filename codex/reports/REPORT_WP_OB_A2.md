## Changes By Finding

1. Baselines now instantiate `pysindy.SINDy` in `baselines.fit_pysindy_baseline`. SINDy uses `SmoothedFiniteDifference()` and `CustomLibrary`; W-SINDy uses `WeakPDELibrary(function_library=..., spatiotemporal_grid=t, K=200)`. Both use `STLSQ(threshold=s, normalize_columns=True)` over the frozen threshold grid. The AICc residual is the PySINDy optimizer regression target captured during `optimizer.fit`; this is the weak-form target for W-SINDy because PySINDy passes the transformed target into the optimizer. `pysindy_parameters` is built from the instantiated model, optimizer, differentiation method, and libraries.
2. Baseline noise now uses one generator per `(seed, system, method)` in `run._baseline_record`, then draws the two trajectories sequentially.
3. `fhat.basis_ivp_fhat` now limits the production interval at the first real leading-coefficient zero outside the training domain, with margin `1e-3 * R`, records `effective_interval`, and raises `ValueError` outside that interval so trajectory metrics become `inf` without aborting the run.
4. `run_sanity` now uses the same full production interval as the run and also integrates both training trajectories with the exact-chain `fhat`. Plausibility check 1 uses the updated `1e-4` threshold.
5. `run.annihilator_state_for_system` now checks `n_exact` for the selected class with the generalized oracle and caches by `(system, r, d)`. Componentwise `(r, d)` comparison is no longer used. Records include `selected_n_exact`.
6. Records now include annihilator operator coefficients in `z`, `(r, d)`, `fhat_fit_coefficients`, `fhat_effective_interval`, `fhat_fail`, selected baseline terms with coefficients, selected threshold, AICc, RSS, per-trajectory `NRMSE_x`, per-trajectory `R2`, and per-trajectory fail reasons.
7. `--workers` now dispatches record jobs with `ProcessPoolExecutor` over `(system, eta, seed, method)`. The parent process appends records as futures complete; resume still skips existing keys.
8. Tests now cover production `basis_ivp_fhat`, Gompertz-style interval limiting, leading-zero failure, PySINDy-backed record generation and parameters, distinct baseline noise streams, and the `n_exact` state rule. `run_one_synthetic_record` and the old synthetic fixture test were removed.
