# REPORT WP-RC-A

## Status

Implemented the direct sparse-regression reality check in Python as an isolated v3 diagnostic. No existing v3 code,
tests, result records, or `docs/REALITY_CHECK_DIRECT_REGRESSION.md` were changed.

## Files

- `experiments/annihilator_gate2a_v3/diagnostics/direct_regression_check.py`
  - 23-term frozen library.
  - Closed-interval admissibility check using endpoints, singular points, and the v3 evaluation grid.
  - True term sets and coefficients for F1-F10.
  - BS selection for k=1..4 with unregularized least squares and chi-square acceptance.
  - STLSQ with RMS column normalization, threshold 0.1, at most 20 iterations, no ridge.
  - JSONL record writer with resume-by-key for `(function, seed, method)`.
  - `--exact`, `--seeds`, `--functions`, `--summarize`, and `--outdir` CLI.
- `experiments/annihilator_gate2a_v3/tests/test_direct_regression_check.py`
  - Library and admissibility checks.
  - Exact true-term reconstruction checks.
  - Category checks.
  - BS selection-rule check.
  - Summary threshold checks using a baseline record generated by the new module and Annihilator fixtures derived
    from real `records_merged.jsonl`.
  - Tau check.
- `experiments/annihilator_gate2a_v3/results/reality_check_direct/exact_check.json`
  - Exact-data implementation check output.

## Record Field List and Origin

The first `exact_check.json` record has these fields:

| Field | Origin |
|---|---|
| `function` | Run input: function key. |
| `seed` | Run input: seed. Exact mode uses seed 0 with eta 0. |
| `method` | Analysis pipeline: `BS` or `STLSQ`. |
| `category` | Analysis pipeline: category from selected terms versus frozen true term set. |
| `fail_reason` | Analysis pipeline: reason when category is `FAIL`; otherwise null. |
| `selected_terms` | Analysis pipeline: chosen library term names. |
| `coefficients` | Analysis pipeline: fitted coefficients in original units. |
| `k` | Analysis pipeline: size of selected term set. |
| `rss` | Analysis pipeline: residual sum of squares from the selected fit. |
| `T` | Analysis pipeline: `rss / sigma^2`. |
| `critical` | Analysis pipeline: `scipy.stats.chi2.ppf(0.99, n-k)`. |
| `accepted_at_k` | Analysis pipeline: number of accepted BS subsets at the chosen k; null for STLSQ. |
| `fits` | Analysis pipeline: number of least-squares fits attempted for the method. |
| `sigma` | Analysis pipeline: `sigma_eff(values, eta, tau)`. |
| `coefficient_relative_error` | Analysis pipeline: relative coefficient error when all true terms are present. |
| `training_residual_relative` | Analysis pipeline: `sqrt(rss/n) / rms(values)`. |
| `grid_error_relative` | Analysis pipeline: dense 10,000-point same-domain error. |
| `grid_error_reason` | Analysis pipeline: nonfinite/no-model reason for grid error; otherwise null. |
| `extension_error_relative` | Analysis pipeline: 10,000-point right-extension error. |
| `extension_error_reason` | Analysis pipeline: nonfinite/no-model reason for extension error; otherwise null. |
| `wall_clock_seconds` | Analysis pipeline: elapsed seconds for the method selection. |

For noisy `records.jsonl`, the same field list is used for each `(function, seed, method)` record.
