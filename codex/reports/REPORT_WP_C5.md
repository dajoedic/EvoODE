## Implementation

`read_heartbeat` now splits the JSONL stream at `start` events and analyzes the last segment that
contains at least one `level` event.

Returned heartbeat metadata was extended with:

- `total_segments`
- `selected_segment`
- `discarded_segments`
- `discarded_level_events`

`analyze()` writes the externally visible fields to
`outputs/studies/regression/wp_b1_wasted_levels/cell_wasted_levels.csv`:

- `heartbeat_segments`
- `selected_heartbeat_segment`
- `discarded_heartbeat_segments`
- `discarded_heartbeat_level_events`

The markdown report generated by the script also reports total discarded segments and discarded
level events.

## No-start handling

A stream with `level` events before any `start` is treated as an implicit segment with
`start_time = missing`. If the stream contains no `start` at all, those levels are still analyzed,
and the downstream duration fallback already present in the script uses the first level timestamp.

If a later restarted segment exists, the prefix segment is not silently lost: it is counted in
`discarded_segments`, and its level events are counted in `discarded_level_events`.

An empty trailing segment, for example a final `start` with no `level` events yet, does not erase the
last analyzable segment. It is counted as a discarded segment with 0 discarded level events.

## Fixtures

Fixtures are derived from real local heartbeat records under `outputs/`.

The test discovers real single-segment heartbeat files with exactly one `start` and at least 3
`level` events. A Python pre-check found 130 such local files.

The first two files in sorted order at the time of this report were:

| fixture | starts | levels | malformed |
|---|---:|---:|---:|
| `outputs/docker_wp_h2_default/tasks/cell_000061.heartbeat.jsonl` | 1 | 13 | 0 |
| `outputs/docker_wp_h2_uid12345/tasks/cell_000061.heartbeat.jsonl` | 1 | 13 | 0 |

Per the task note, the two-segment case is built by concatenating two real one-segment streams; it is
not an independently observed completed restart stream from C-3. For the chosen pair, the expected
discard counts are 1 discarded segment and 13 discarded level events.

The start-less fixture is derived by removing the real `start` line from a real stream. The empty
trailing segment fixture is derived by appending only the real `start` line from another real stream.

## Tests Added

`test/test_wp_c5_heartbeat_segments.jl` checks:

1. A real single-segment stream matches a legacy copy of the old reader for `start_time`, sorted
   level events, first level row, and `malformed`.
2. A concatenation of two real streams selects only the second segment.
3. Discarded segment and level-event counts are correct.
4. A start-less stream remains analyzable and does not become an empty heartbeat.
5. An empty trailing segment does not replace the last non-empty segment.
